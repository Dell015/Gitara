# Gitara starter catalog.
#
# One song per block. Chords only, never lyrics.
#
#   == Title | Artist | Genre | Year | BPM | Capo | Check
#
# Year, BPM and Capo can be left empty. Genre is one of the fixed list (Pop, Rock, Folk, OPM...).
# Check says how sure the chart is: "ok" = well known, "verify" = please check it by ear.
#
# Then one line per section:   Verse: G D | Am | G D | C
#   - A line with no "|":  each chord is one bar.   Am F C G   = four bars
#   - A line with "|":     bars are split by "|", and chords inside a bar share it evenly.
#                          C G | Am F   = two bars, two chords each (2 beats per chord)
#   - "." holds the chord for another beat slot, N.C. is a rest
# And optionally the order:    Order: Verse x2, Chorus, Verse
# Without "Order:" the sections play once each, top to bottom.
#
# A block with no sections is added to the catalog as a song with no chart yet: people can find it,
# like it and add their own version. To contribute a chart, add section lines under the song.
